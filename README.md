# The Meaning of Balance / 平衡的意义

一本探讨世界平衡性与人生意义的哲学思考书籍。

## 📖 关于本书

本书从物理学、社会心理学等多个角度探讨世界的平衡性，并试图通过打破这种平衡来寻找人生的意义。作者认为世界并非简单的零和游戏，而是存在着可以被主观化的快乐与痛苦，这为寻找人生意义提供了可能。

## 🛠️ 本地构建

### 前置要求

- [Rust](https://www.rust-lang.org/) 和 Cargo
- [mdBook](https://github.com/rust-lang/mdBook)

### 安装 mdBook

```bash
cargo install mdbook
```

### 构建和预览

```bash
# 构建静态网站
mdbook build

# 本地预览（支持热重载）
mdbook serve
```

构建完成后，静态文件将生成在 `book/` 目录中。

## 📁 项目结构

```
.
├── book.toml          # mdBook 配置文件
├── src/               # 书籍源文件

│   ├── preface.md     # 前言
│   └── chapter_*.md   # 各章节内容
```
