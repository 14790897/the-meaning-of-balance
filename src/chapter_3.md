# Chapter 3

从历史上看，过去是物质决定人受到物理世界的平衡影响更大，当人吃不饱的时候，人的心思全在食物上，获得食物多就会开心，而这和物理世界高度相关，意味着个人的主观的影响会大大减少，随着物质需求逐渐满足，现在是精神决定你眼中的平衡多，因此需要更加关注自身对世界价值观的构建。
然而，要找到自己合适的发向却是要付出巨大的努力，同时自己合适的方向是会产生变化的，每个阶段喜好的东西不同，而有一点却可以始终保有，那就是一个人的思维能力。
一个人的思维呢可以帮助他分辨出什么是自己想要的，事物的好和坏分别是什么，有助于辩证地看待思考问题，同时明白这个世界上几乎没有绝对的事情以知道喜好是会改变的。接下来我会举一些例子说明要如何的去训练思维，比如说萨特的“人是绝对自由的”和福柯的“人不自由”，这两方都说的很绝对，我们应该要知道绝对的事情是几乎不存在，所以我们首先要明白人在某些方面是自由在另一些方面是不自由，而且这种自由不自由会随着时间相互变化，同时他们的比例也会增大减小,
